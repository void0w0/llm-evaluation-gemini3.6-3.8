# LlmEvaluationGemini3.6-3.8
Google Gemini APIを使った複数LLMモデル3.6-3.8の比較評価（応答時間・文字数・回答品質）

### 使用技術
- Python / Jupyter Notebook
- Google Gemini API

### 評価モデル
- gemini-3.6-flash
- gemini-3.7-flash
- gemini-3.8-flash

### 評価観点
- 応答時間（秒）
- 文字数
- 回答の質（考察）

### セットアップ
1. Google AI StudioでAPIキーを取得
2. 環境変数に設定：export GEMINI_API_KEY="your-api-key"
3. jupyter notebookを起動
